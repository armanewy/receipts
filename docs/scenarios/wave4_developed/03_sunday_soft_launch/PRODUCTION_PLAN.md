- Realistic fictional photos needed: 6-8.

- Text posts needed: 10-14 Threadline posts/replies.
- Comments needed: 30-45 total across Loop, Frame, and Threadline.
- DMs/snaps needed: 2-3 Blink artifacts.
- Profiles needed: 5 profile surfaces: Mara, Jace, Sol, @softwatcher, showcase account.

- Optional Eden bracelet story.

## Short Video Assets

- Cropped Studio 6 exit clip for S01-R01.

## Text And Comment Assets

- Loop comments should start judgmental, then split into "check Frame" and "full clip exists" subthreads.
- Frame comments should reference @softwatcher without sounding like hint text.
- Threadline should include timestamped posts, quotes, and replies that show the spread.
- Blink copy should be brief and natural. It should not explain the whole scenario.

## Continuity Objects

- Orange jacket: repeated clearly in Loop, Frame, and Blink.
- Studio 6 doorway/rack: repeated enough to connect surfaces without requiring tiny text.
- Jace room setup: shirt, mug, lamp, or chair visible in Friday and Sunday clips if S01-R14 stays.
- Monday showcase graphic: same fictional event name across Frame and Threadline.
- Handles and timestamps: consistent across app surfaces.

## Visual Motifs

- Orange jacket as public symbol.
- Boxes/packed apartment items as private-timing signal.
- Studio rack/doorway as context.
- Creator showcase graphics as benefit trail.
- Cropped screenshot edges as social-media circulation texture.

## Asset Risks

- Jace's sad clip can feel melodramatic if overplayed.
- The orange jacket can become too obvious if every asset points at it too loudly.
- Threadline can become recap-heavy if posts summarize what the player should infer.
- Blink can feel too convenient if the private screenshots are too clean.
- Eden can distract if the side path gets more visual weight than the core graph.

## Easiest Assets

- Threadline posts and replies.
- @softwatcher profile history.
- Showcase chatter.
- Frame queued carousel cover.
- Blink text screenshot for Thursday timing.

## Hardest Assets

- Cropped and fuller Loop clip pair.
- Jace emotional clip with believable restraint.
- Jacket continuity across multiple surfaces.
- Timestamp formatting that is readable but social-native.
- Realistic fictional cast consistency.

## Receipts That Should Not Rely On Tiny Visual Detail

- S01-R02 should use caption/context and visible Sol presence, not small labels.
- S01-R07 should show clear upload order through normal timestamp display.
- S01-R10 should make Jace's prior public interaction readable through a visible comment/repost marker.
- S01-R14 should remain optional because outfit/room comparison can become too visual-detail dependent.

## Realistic-But-Fictional People Safety

- Use fictional cast reference sheets with no public-figure resemblance.
- Avoid real platform branding, real app UI, real venue names, or real creator-program names.
- Prefer partial faces, mirrored angles, hands, rooms, clothing, and props for continuity-heavy assets.
- Keep all handles fictional and check that they do not match known public figures.
- Maintain an asset rights log with prompt, generated output ID, edit notes, character identity, app surface, and usage.

## Production Scope Recommendation

For MVP packet expansion, produce the written content first, then generate media placeholders, then only create final media for the first playable slice. The scenario can be tested with text and still placeholders before investing in polished video.
