# First Unlock

## Unlock Target

Loop.

## Exact Content That Unlocks The Next App

Mina's third Frame story card includes a repost sticker:

`Dax's table clip`

Visible sticker text:

`you all saw the table clip`

The sticker opens a Loop clip posted by `@daxmoreno`.

## Supporting Social References

Frame story replies/comments:

- `@daxmoreno`: "the clip says enough tbh"
- `@localplateclub`: "where's the table clip?"
- `@greenroommara`: "not me opening Loop for context"

Mina pinned reply:

`I wish the table clip wasn't the part people needed.`

## What The Player Should Wonder

- Did Rhea leave because she had just been confronted?
- Was the table clip actually from the same moment as the screenshot story?
- Why does Mina point to the clip while also saying she wishes people did not need it?

## Unlock Language Without Tutorial Feel

Use in-world language:

- "Dax's table clip is everywhere."
- "The story keeps pointing to the Loop."
- "People are reacting to the clip before the screenshot even appears here."

Avoid direct UI phrasing like:

- "Loop unlocked."
- "Go to Loop now."
- "Find the next clue."

## What Loop Should Promise

Loop should promise the emotional table moment:

- Rhea standing up during Mina's toast.
- Dax's caption framing it as enough context.
- Comment disagreement around the date.
- The next path toward @porchwatch on Threadline.

## Slice Exit Criteria

The first slice is successful if the tester wants to open Loop because the table clip feels socially necessary, not because the product told them to.
