# Receipts Prototype

This is a standalone mobile-first prototype for The Empty Fifth Chair. It uses static local data in `app.js` and does not require a build step.

Open `index.html` in a browser, or serve this directory with any static file server.

Prototype coverage:

- Frame, Loop, Threadline, Blink, and Report surfaces.
- App unlocks through in-world content references.
- Fifteen saveable receipts.
- Receipt tray with apparent and updated meanings.
- WHO / WHY / WHEN / HOW report slots.
- Correct, partial, and wrong ending states.

Current limitation:

- Media is represented with authored placeholders, not final generated assets.
