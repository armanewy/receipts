# MVP Receipt Requirements

## Formal Receipt Model

Each receipt should carry:

- Receipt ID.
- Title.
- App.
- Content type.
- Required or optional.
- Apparent meaning.
- Actual meaning.
- Report slot supported.
- Depends on receipt IDs.
- Acceptable substitute receipts.
- Wrong theories it helps disprove.
- Production requirements.
