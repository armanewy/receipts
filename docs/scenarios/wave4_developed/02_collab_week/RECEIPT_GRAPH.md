## Minimum Winning Receipt Bundle

The minimum winning bundle should require receipts that cover timing, method, benefit, and private context:

- CW-05: early recap teaser.
- CW-06: cropped Blink screenshot post.
- CW-10: solo-week waitlist sticker.
- CW-11: archived solo teaser dated before the blowup.
- CW-14: older chat header.

This bundle supports WHO, WHY, WHEN, and HOW without relying on one all-purpose receipt.
