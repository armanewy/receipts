# First Slice Overview

## Scenario

The Empty Fifth Chair.

## Slice Goal

Test whether the first 5-8 minutes create the intended browsing pull:

- Surface event.
- First app browsing.
- First receipt.
- First wobble.
- First app unlock.

## First App

Frame.

Frame is the correct first surface because the empty chair, renamed highlight, old group warmth, profile snippets, tags, and story comments can all be understood quickly on mobile.

## Included Slice Content

- Mina's empty-chair story carousel.
- Mina profile snippet.
- Rhea profile snippet.
- Old Supper Five highlight card.
- "Supper Four" highlight rename.
- Story comments and reactions.
- First required receipt: S02-R01.
- First timing/context receipt: S02-R02.
- Optional warmth/context receipt: S02-R03.
- First unlock trigger into Loop through Dax's table clip.

## Player Understanding Target

By the end of the slice, the player should believe the public story enough to care, but also notice one problem:

The group image seems to have changed before the public Threadline crop became the whole story.

The player should want to open Loop to see whether Rhea really left dinner the way the Frame story implies.

## What This Slice Must Not Do

- It must not reveal Mina as the answer.
- It must not introduce Cedar Room yet except as optional background in Mina's profile.
- It must not include Blink content.
- It must not show @porchwatch's screenshot yet.
- It must not turn comments into instructions.
- It must not change the true timeline.

## Receipts Introduced

- S02-R01: Empty Fifth Chair.
- S02-R02: Supper Four Rename.
- S02-R03: Supper Five Warmth.

## Slice Exit

The slice ends when the player taps the visible Loop reference:

"Dax's table clip is everywhere."

The next app should promise the emotional table moment and the first timestamp wobble.
